Community Wi-Fi hotspots usually work the same way: you join an open network, a login page appears, and you enter a voucher code to start browsing. If you have never done it before, this guide walks you through each step and explains what to do when something does not work.

## Before you start

You need three things:

- A phone, tablet or laptop with Wi-Fi.
- To be within range of the hotspot. Range depends on the equipment and the building, so stay close to the hosting venue if the signal is weak.
- A voucher code bought from an official seller at the hosting location.

Only buy vouchers from the seller named by the hotspot operator. A code bought from someone else may not work, or may already have been used.

## Step 1: Turn on Wi-Fi and find the network

On an Android phone, open **Settings**, then **Network and internet** or **Connections**, then **Wi-Fi**. On an iPhone, open **Settings**, then **Wi-Fi**. The exact names vary between phone makers, but every phone has a Wi-Fi list in its settings.

Turn Wi-Fi on and wait a few seconds for the list of networks to appear. Look for the exact network name shown at the hosting venue. If you are unsure, ask the seller to show you the correct name, because a fake network with a similar name is one of the most common Wi-Fi tricks.

## Step 2: Join the network

Tap the network name. Most community hotspots are open, so you will not be asked for a Wi-Fi password at this stage. Your phone connects, but you cannot browse yet.

## Step 3: Wait for the login page

A login page, sometimes called a captive portal, should open by itself within a few seconds. This page is where you choose your access and enter your voucher.

If the page does not appear, open your web browser and try to visit any website. Your phone will usually be redirected to the login page. Some phones also show a notification such as "Sign in to network"; tap it.

## Step 4: Enter your voucher code

Type the code exactly as printed, including any letters and dashes. Codes are usually not case-sensitive, but check for easily confused characters such as the number 0 and the letter O.

After you confirm, the page should tell you that you are online and show how much time or data you have left.

## Step 5: Keep an eye on your balance

Time-based vouchers run down whether or not you are actively browsing, so disconnect when you are finished if your voucher allows you to pause. Data-based vouchers only run down as you use data, so large downloads and videos use them up faster.

## When it does not work

Most problems have simple fixes:

- **The login page never appears.** Turn Wi-Fi off and on, then open your browser and visit a simple website. If your phone uses a private DNS setting or a VPN, turn it off temporarily, because these can stop the login page from loading.
- **The code is rejected.** Check each character carefully and try again. If it still fails, go back to the seller with the voucher.
- **You were connected but it stopped.** Your time or data may have run out. Check the balance page, or reconnect to see the login page again.
- **The signal keeps dropping.** Move closer to the hosting venue and away from thick walls.
- **Your phone keeps joining a different network.** Open the Wi-Fi list, tap the other network and choose **Forget**.

If none of this helps, contact the hotspot operator's support team and tell them where you are, which network you joined and what happens when you try to connect.
